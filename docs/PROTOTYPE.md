# 果壁 Studio — 页面原型与交互设计规范

## 1. 设计理念：Apple Studio 极简沉浸感
- **视觉基调**：深邃星墨灰（`#09090B`）搭配苹果毛玻璃卡片（`backdrop-blur-xl` + `1px` 微亮描边），让**用户上传的照片与生成的壁纸成为画面绝对主角**，工具栏退居其次。
- **零心理负担**：顶部明确标注「公益免费版 · 欢迎提意见」，无锁头、无充值弹窗、无“开通会员去水印”，极大降低体验阻力。

## 3. 关键交互细节（提升“果味”体验）

1. **三秒上手（零空白页）**：
   - 首次打开页面，画布默认加载一张内置的高颜值示例图（支持一键切换「人像」「萌宠」「晚霞山海」3 种内置演示图），用户**无需翻找相册就能立刻点按钮体验效果**。
2. **真机级 UI 覆盖预览**：
   - **iPhone**：还原灵动岛、状态栏信号电量、自定义字体/颜色锁屏时钟、锁屏小组件、底部快捷按钮；切换「主屏模式」可预览 App 图标网格 + 自动柔焦背景效果。
   - **iPad**：提供「竖屏 / 横屏一键旋转」，直观检验 iPad 旋转后主体会不会被裁切。
   - **Mac**：还原 macOS 顶部半透明菜单栏与底部毛玻璃 Dock 栏。
3. **安全区可视化开关**：
   - 一键打开红色/琥珀色虚线参考框，明确标示“灵动岛避让区”“时钟最佳视觉区”“iOS 景深触发黄金线（距顶约 24%~32%）”。
4. **顶部留白智能延展（Smart Top Breathing Room）**：
   - 很多用户上传的 4:3 人像或宠物照，放进细长的 iPhone 屏幕后头顶直接撞到时钟。开启「顶部智能延展」后，系统自动向下微移主体并在顶部自然延伸天空/氛围渐变背景，立竿见影解决痛点。
5. **一键晒图海报（天然裂变钩子）**：
   - 除导出纯净壁纸原图外，提供「生成展示海报」按钮：自动将作品装入精美 iPhone + Mac 组合样机中并附带极简色卡与参数标签，方便直接发小红书/朋友圈。
6. **轻量化反馈闭环**：
   - 导出成功后弹出温和的小提示（“这次效果还满意吗？哪里可以更好？”），右上角常驻「提建议」，让每一次免费体验都沉淀为产品迭代方向。
